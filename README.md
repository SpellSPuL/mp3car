# mp3car
Archive of in-car 286 software driving a Hitachi LCD over RS-232 alongside an LED VU meter, Winamp, and a keyboard plugin.

Includes -

Say The Time - Have the computer tell you the time
CD Operations - Open, close or play optical disks
Winamp IR remote - Packard Bell Fast Media Remote control for Winamp
Keypad Controller - Plug-in to control Winamp
LED array VU meter - Winamp plug-in that drives a LED VU meter
m3uf - Program that numbers and formats m3u playlists for printing.
LEDographer - "scripting" utility to control the LED array.
DOS Batch Helpers - Small programs that drive a Hitachi LCD under DOS.
